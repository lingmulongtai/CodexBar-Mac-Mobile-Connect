# PC同士の接続

Windows版・Mac版とも、**Settings → Mobile Connect** で送信と受信を設定します。送信元は使用量・リセット時刻・保存済みの履歴・費用／トークン集計を取得し、受信側は同じデータを表示します。プロバイダのCookieやAPIキーは送信しません。

## WindowsからMac／別のWindowsへ

1. 送信元で必要なプロバイダを接続します。
2. **Share this PC** でLANまたは **Tailscale (no exit node)** を選び、使用量の共有を有効にします。標準のTCPポートは **43825** です。
3. 送信元の接続コードをコピーします。
4. 受信側の **Receive from another PC** に、分かりやすいPC名と接続コードを入力し、**Save and connect** を押します。
5. **Display source** でそのPCを選択します。接続状態と最終受信時刻を確認してください。

MacからWindowsへの送信も同じ手順です。Windows同士・Mac同士でも同じ接続コード形式を使います。自分のPCの表示へ戻すときは **This PC** を選びます。接続を削除するために再接続する必要はありません。

## Tailscale：exit nodeは不要

両方のPCを同じtailnetへ接続し、送信元の`100.x.x.x`アドレスを使用します。受信側のexit nodeは **None／なし** のままで構いません。アプリのポートへの到達をTailscaleのアクセスルールと送信元のファイアウォールが許可している必要があります。アプリはVPN・ファイアウォール設定を自動変更しません。

Tailscale CLIが見つからないときは、送信元のTailscaleアドレスを手動で指定できます。接続コードにパブリックIPやホスト名は使えません。

## 複数端末・双方向の表示

スマホ・タブレット・別のPCを同じ送信元へ接続できます。PC側では最大16台分の送信元を保存し、表示する送信元を1台選びます。

AでBを表示しながら、BでAを表示することもできます。それぞれが共有するのはそのPC自身で取得したデータです。受信したBのデータをAが再送することはありません。受信への切替でローカルのプロバイダ設定は変更されません。

履歴と費用は選択中の送信元PCの保存データ・集計期間・タイムゾーンを使います。共有されないプロジェクト／会話の詳細は表示しません。受信側の古いデータや別アカウントで不足分を補完しません。

送信元がオフラインの間は最後に受け取った値とオフライン状態を表示します。送信元を切り替えた場合、以前のPCへの遅い応答は破棄します。送信元の再起動では同じコードを継続使用できますが、鍵を失効した場合は全受信端末で新しいコードを登録してください。

## 接続情報の保存

Windowsは既存のDPAPI、Macはlogin Keychainの鍵による暗号化で接続情報を保存します。Macの設定ルートは`~/Library/Application Support/CodexBar-Mac-Mobile-Connect`です。アプリの更新でこのディレクトリを消さないでください。

接続コードは使用量の閲覧権限を持ちます。公開README、スクリーンショット、課題報告へ貼らないでください。

## Mac版の範囲

macOS 14以降、Apple SiliconとIntel向けです。Macでは現在、Windows専用の自動起動・OS通知・通知音・Stay Awake・PowerToys連携・バッテリー節約の自動追従を無効表示にします。手動の省電力モード、定期取得、履歴、受信／共有は別の機能です。

Macの更新はAboutの確認からMac用リリースを開き、DMGでApplicationsのアプリを置き換えます。Windows用EXEを自動取得・起動しません。

ユーザーのMac実機は現在利用できないため、実機間のTailscale接続とGoogleログインの受け入れ確認は未実施です。ネイティブCIのビルド・テスト・起動結果はリリースの検証記録に区別して掲載します。

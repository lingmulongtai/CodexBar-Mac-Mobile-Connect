# CodexBar + Mobile Connect for Mac v0.72.0

MacからWindows・別のMacへ使用量を共有し、WindowsまたはMacで取得したデータをMac側で表示できます。Androidとも同じ暗号化された共有データを利用します。

- Settings → Mobile Connectに、共有と他のPCからの受信をまとめました。
- 使用量、リセット時刻、保存済み履歴、費用／トークン集計を送信元から取得します。
- LANまたは同じTailscaleネットワークで接続。exit nodeは不要です。
- 送信と受信は独立し、受信データの再送による循環を防止します。
- 接続情報はlogin Keychainの鍵によるAES-GCMで保護します。
- Mac専用の設定保存先と更新先を使用し、Windows用EXEを起動しません。

## ダウンロードと更新

macOS 14以降が対象です。Apple Siliconは`macOS-arm64.dmg`、Intelは`macOS-x86_64.dmg`を選んでください。DMGからApplicationsへコピーします。更新時はアプリを終了して置き換え、設定フォルダは保持してください。

この配布物は**ad-hoc署名**です。Apple Developer ID署名・公証済みではありません。`SHA256SUMS`とアーキテクチャ別のビルド記録を添付します。

[PC同士の接続手順](https://github.com/lingmulongtai/CodexBar-Mac-Mobile-Connect/blob/main/docs/CONNECTING.md) · [3つのアプリのProject](https://github.com/users/lingmulongtai/projects/3)

## 検証の範囲

Mac実機を利用できないため、ユーザー端末間のTailscale接続・Googleログインの受け入れ確認は未実施です。Apple Silicon／IntelのネイティブCIで、Rust／フロントエンド、Keychain保存、暗号化通信、DMG内の実行ファイルと署名、アプリ起動・画面を検証してから公開します。画面には実アカウントを含まない専用の検証プロファイルを使います。

現時点のMac版では、Windows専用の自動起動・OS通知・通知音・Stay Awake・PowerToys・バッテリー節約の自動追従は利用できません。UIに対応範囲を表示します。
